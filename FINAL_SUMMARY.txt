KEY DECISIONS & DATA STRATEGY
================================================================================

GEOGRAPHIC SCALE MISMATCH RESOLVED:
- Frontend: 20 Northeast India districts (sub-national)
- Snowflake: 25 nations worldwide (country-level)
- Solution: Dual-mode display
  * District data labeled as "DEMO DATA" (preserved for UI/UX)
  * Nation data labeled as "SNOWFLAKE LIVE" (when connected)
  * Never map nation scores to districts (scientifically invalid)

DATA SOURCE BADGES:
- 🎭 DEMO DATA badge: Amber, flask icon (district-level mock data)
- ✅ SNOWFLAKE LIVE badge: Green, database icon (nation-level from DB)

SNOWFLAKE CONNECTION STATES:
- Green (Connected): Database accessible, live data available
- Amber (Offline): Backend running, credentials missing/invalid
- Red (Error): Backend not responding
